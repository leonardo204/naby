# 대화 학습 보강 (P3-M13)

## 1. 문제

naby의 학습 루프는 뼈대가 서 있다 — 턴 중 기억 제안, 세션 후 회고, 교차 세션 확증, 접근 기반 감쇠. 그런데 네 곳이 비어 있다.

- **선호가 바뀌면 옛 기억과 새 기억이 공존한다.** 값이 크게 바뀌면 확증이 리셋될 뿐, "이 기억이 저 기억을 대체했다"는 개념이 없다.
- **감쇠가 절벽이다.** 30일/90일 고정 기준이라, 매일 쓰이던 기억도 한 번 안 쓰이기 시작하면 같은 속도로 늙는다.
- **근사 중복 기억이 주입 예산을 같이 먹는다.**
- **어투·문장·요청 패턴을 배우는 전용 채널이 없다.** 스타일은 우연히 기억으로 잡힐 때만 반영된다.

## 2. 조사 근거 (2026-08-04, 세 갈래)

- **모순 해소는 결정론이 이긴다.** 의미 매칭만 LLM에 맡기고 승자는 코드가 타임스탬프로 뽑는 방식이, LLM에게 최신 판정까지 맡기는 방식보다 24~40%p 우세하다(arXiv:2606.01435). Mem0의 ADD/UPDATE/DELETE/NOOP 4연산(arXiv:2504.19413)과 Zep/Graphiti의 "삭제 대신 무효화 타임스탬프"(arXiv:2501.13956)가 실무 표준 모양이다.
- **감쇠는 접근이 강화하는 연속 모델이 표준이다.** MemoryBank는 `R = e^(−t/S)`에 회상마다 S를 올리고, 망각을 삭제가 아니라 강등으로 처리한다(arXiv:2305.10250, AAAI'24). naby의 "선택이 곧 접근"은 이 문헌과 정확히 일치한다.
- **중복 억제는 MMR이 표준이다**(Carbonell & Goldstein 1998). 관련도에서 이미 뽑힌 것과의 유사도를 빼는 재점수.
- **암묵 신호는 가중치 학습엔 시끄럽고, 설명 수준 학습이 정답이다.** 사용자 편집에서 자연어 선호 설명을 추론해 작업 유형별로 저장·검색하는 PRELUDE/CIPHER가 편집 비용 최소를 기록했다(NeurIPS 2024, arXiv:2404.15269). 대화 로그의 암묵 피드백을 직접 학습 신호로 쓰면 결과가 엇갈린다(EMNLP 2025, arXiv:2507.23158).
- **적응은 신중하게, 보이게.** 추론된 선호는 보이고·수정되고·지워질 수 있어야 하며, 전역 어조를 바꾸는 추론은 채택 전에 확인한다(Microsoft HAX).

유지가 확인된 것 — hot-path(턴 중)/background(회고) 분리는 LangMem이 공식화한 구조 그대로이고, 교차 세션 확증(3회)은 조사된 어느 시스템보다 엄격한 naby 고유 규칙이라 그대로 둔다.

## 3. 설계

### 3.1 M13a — 기억 갱신 4연산 + 대체 이력

회고 패스가 기억 후보를 낼 때 한 단계를 추가한다.

1. **매칭(코드)** — 후보와 같은 범위의 기존 기억 중 어휘 유사도 상위 후보를 고른다(기존 토크나이저 재사용).
2. **판정(LLM, 좁게)** — 회고 judge가 쌍마다 `equivalent | refines | contradicts | unrelated`만 답한다. 기존 evidenceQuote 축자 검증을 그대로 통과해야 한다.
3. **연산(코드, 결정론)** —
   - `equivalent` → **NOOP** + 확증 관측 1건(지금의 corroboration 경로).
   - `refines` → **UPDATE** — 같은 key에 값 변경 제안(기존 putMemory 경로, 확증 리셋 규칙 그대로).
   - `contradicts` → **ADD** 새 후보 + **대체 예약**. 새 기억이 `confirmed`가 되는 순간 옛 기억에 `superseded_at`·`superseded_by`를 찍는다. 승자는 언제나 최신 타임스탬프 — LLM이 고르지 않는다.
   - `unrelated` → **ADD**.

대체 규칙 세 가지.

- **대체는 확정이 조건이다.** proposed 후보는 아무것도 대체하지 못한다. 확정(사용자 승인 또는 확증 승격) 전까지 옛 기억이 계속 산다.
- **일시적 사실은 안정적 사실을 대체하지 못한다.** 추출 시 `volatility: stable | transient` 태그를 단다("이번 주 베를린 출장"이 "리스본 거주"를 지우면 안 된다 — 문헌이 지적한 대표 오류). 태그가 없는 기존 행은 stable로 본다.
- **대체는 삭제가 아니다.** superseded 행은 주입 후보에서 빠질 뿐 남는다. 기억 브라우저가 대체 사슬을 보여주고, 사용자는 대체를 되돌릴 수 있다(주권 원칙).

스키마 v12: `memory_items`에 `superseded_at INTEGER`, `superseded_by TEXT`, `volatility TEXT` — 컬럼 존재 게이트 ALTER, 백필 없음. 구현에서 `prov_supersedes TEXT`가 하나 더 붙었다. 대체 예약을 어딘가에 두어야 하는데, 값 안의 표식은 모델이 읽고 사용자가 고치는 문장에 상태를 숨기는 셈이라 프로버넌스의 명시적 필드로 두었다.

### 3.2 M13b — 연속 강도 감쇠 + 주입 다양성

30일/90일 절벽을 **강도 모델의 특수해**로 일반화한다.

- `memory_items.strength REAL NOT NULL DEFAULT 1`(v12). 주입에 선택될 때마다 1씩 오르고 `STRENGTH_CAP = 12`에서 멈춘다(불멸 방지).
- 잔존도 `R = exp(−t / (S × 30일))`, t는 마지막 사용 이후 경과.
- **stale** = `R < e^(−1)` (S=1이면 정확히 현행 30일), **리뷰 큐** = `R < e^(−3)` (S=1이면 정확히 현행 90일). 기존 설치에서 행동 변화가 없고, 자주 쓰인 기억일수록 천천히 늙는다. 리뷰 큐가 "고정 나이"에서 "강도 하락"으로 바뀌므로 매일 쓰이는 기억은 영영 들어가지 않는다.
- **관련도 우선 원칙은 불변이다.** R은 지금의 신선도 불리언 자리(관련도 다음 동점 처리 계층)에 연속값으로 들어간다. 누적된 나이가 관련도 차이를 이기는 일은 구조적으로 불가능하다 — P3-M10에서 곡선을 기각한 이유가 그대로 지켜진다.
- **MMR 중복 억제** — 예산을 채울 때 이미 뽑힌 항목과 토큰 유사도가 `MMR_SIM_THRESHOLD = 0.6`을 넘는 후보는 뒤로 미룬다. 떨어뜨리지 않고 미루기만 한다 — 예산이 남으면 들어온다.

### 3.3 M13c — 스타일 프로필

두 부분으로 나눈다. 추론이 필요한 것과 세기만 하면 되는 것.

**선호 설명(LLM 추론, 회고 확장).** 회고 패스에 과제를 하나 더한다 — 사용자의 교정·재요청·자유 서술 답변에서 **작업 유형별 자연어 선호 설명**을 뽑는다("문서를 요청할 때 ~한다 평서형을 원한다", "결론을 먼저 듣기를 원한다"). 후보는 `type: procedural`, `scope: user`, key는 `style/<대상>/<슬러그>`로 네임스페이스를 갖는 평범한 기억 항목이다. 기존 기계를 그대로 통과한다 — proposed로 태어나고, 리뷰 UI에서 승인되거나 3세션 확증으로 승격된다. 단 **전역 어조를 바꾸는 항목(`style/global/*`)은 확증으로 자동 확정되지 않는다** — 반드시 사용자 승인을 거친다(HAX "신중한 적응").

**문체 지문(결정론, LLM 없음).** 회고 스윕이 사용자 발화에서 평균 문장 길이, 어미 분포(~다/~요/~함), 질문 비율, 목록 사용률을 세서 `style.fingerprint` 설정 키에 JSON으로 저장한다(계산 시각·표본 수 포함). 페르소나 턴 시스템에 한 줄로 압축 주입된다. 설정에서 읽기 전용으로 보인다.

둘 다 `canCaptureMemory` 게이트를 그대로 따른다 — 학습을 끄거나 세션을 학습 제외로 표시하면 스타일도 배우지 않는다.

## 4. 거절한 대안

- **LLM에게 모순의 승자 판정까지 맡기기** — 결정론 분리가 24~40%p 우세하다는 실증을 따른다. LLM은 "같은 사실인가"만 답한다.
- **감쇠 곡선을 관련도와 곱하기** — 누적된 나이가 관련도를 이기게 된다. P3-M10의 기각 결정 유지. R은 동점 처리 계층에만 산다.
- **암묵 신호로 모델/가중치 직접 조정** — EMNLP 2025가 보여준 잡음 문제. 설명 수준(기억 항목)으로만 배운다.
- **스타일 자동 적용** — 전역 어조 변경의 무단 채택은 사용자가 눈치채기 어려운 방식으로 에이전트를 바꾼다. 보이는 기억 항목 + 승인 경로로만 간다.
- **새 스위치 추가** — 스타일 학습 전용 토글은 두지 않는다. `memory.learningEnabled`와 세션 학습 제외가 이미 그 질문에 답한다.

## 6. 구현 상태

- ✅ **M13a — 기억 갱신 4연산 + 대체 이력**
  - 스키마 v12. `memory_items`에 `superseded_at`·`superseded_by`·`prov_supersedes`·`volatility`·`strength`를 컬럼 존재 게이트 ALTER로 더한다. 백필은 없다. 컬럼이 다섯인 것은 계획보다 하나 많다 — 대체 예약을 값 안의 표식이 아니라 프로버넌스의 명시적 필드(`prov_supersedes`)로 두었다.
  - 매칭은 코드(`src/runtime/memory-consolidation.ts`의 `matchCandidates`, 주입 토크나이저 재사용), 판정은 LLM이 쌍 관계만, 연산은 코드(`applyConsolidation`)가 결정한다. 승자는 언제나 최신 타임스탬프다.
  - 대체는 확정이 조건이다. 제안 단계에서는 예약만 남고, 확증 승격 경로와 `/api/memory`의 confirm 양쪽이 같은 `activateSupersession`을 거쳐야 도장이 찍힌다.
  - 일시적 사실은 안정적 사실을 대체하지 못한다. 결정 함수와 스토어 양쪽이 같은 거절을 한다.
  - superseded 행은 주입 후보에서 빠지고 확증도 더 쌓이지 않는다. 삭제되지는 않으며, 기억 브라우저가 대체 사슬을 보여주고 되돌리기를 제공한다.
  - 증거: `npm run spike:reflection` **96/96 PASS**(bb·bb2·bb3 결정표/휘발성/매칭, cc 제안은 아무것도 대체하지 않음, dd 확정이 도장을 찍음, ee·ee2 스토어 거절, gg 주입·확증 제외, hh·hh2 NOOP/UPDATE, ii 근거 없는 관계 폐기). `npm run spike:hygiene` **47/47 PASS**(a3 v11→v12 무손실, o·o2 주입 제외와 되돌리기).
- ✅ **M13b — 연속 강도 감쇠 + 주입 다양성**
  - `retrievability = exp(−t / (S × 30일))`, `STRENGTH_CAP = 12`. 주입에 선택될 때마다 강도가 1 오른다(양 드라이버 동일, SQL은 한 문장).
  - stale은 `R < e^(−1)`, 리뷰 큐는 `R < e^(−3)`로 다시 정의한다. S=1에서 현행 30일/90일과 **밀리초까지 같다** — 기존 설치의 행동은 바뀌지 않는다. 기존 함수 시그니처는 그대로 두었다.
  - 스토어의 stale 질의도 강도를 반영한다. `staleBefore` 하나로는 창(window)을 복원할 수 없어 `staleWindowMs`를 함께 받는다. 생략하면 M13 이전 질의 그대로다.
  - 관련도 우선은 구조적으로 지킨다. R 비교는 관련도 차이가 정확히 0일 때만 닿으므로, 쌓인 나이가 관련도를 이기는 일은 표현 자체가 불가능하다.
  - MMR은 예산 채우기 전에 큐만 재정렬한다. 유사도 `> 0.6`인 후보는 뒤로 미룰 뿐 떨어뜨리지 않으며, 예산이 남으면 들어온다.
  - 증거: `npm run spike:hygiene` **47/47 PASS**(k1·k2 절벽 재현이 정확함, k3 자주 쓰인 기억은 40일에도 신선함, k4 상한, l 양 드라이버 강화, m 관련도 우세·m2 동점일 때 R, n1~n3 MMR 후순위와 복귀). `spike:reflection` t3이 "리뷰 큐는 나이가 아니라 강도를 본다"를 별도로 확인한다.
- ✅ **M13c — 스타일 프로필**
  - 회고에 스타일 과제를 더한다. 후보는 `type: procedural`, `scope: user`, key는 `style/<대상>/<슬러그>`인 평범한 기억 항목이고 기존 기계를 그대로 통과한다. 한 회고당 3개로 제한한다.
  - `style/global/*`은 확증으로 자동 확정되지 않는다. 조건은 `shouldAutoConfirmMemory` 한 곳에 모여 있다.
  - 문체 지문은 LLM 없이 센다(`src/runtime/style-fingerprint.ts`) — 평균 문장 길이, 어미 분포, 질문 비율, 목록 사용률, 표본 수. 회고 스윕이 `style.fingerprint` 설정 키에 JSON으로 저장하고, 표본 20개 이상일 때만 페르소나 턴에 영어 한 줄로 주입한다. 설정에서 읽기 전용으로 보인다.
