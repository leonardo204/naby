# naby — 나를 학습해 나를 대신하는 에이전트

naby는 데스크톱에서 쓰는 개인 에이전트 앱입니다. AI에게 일을 시키는 도구는 많습니다. naby가 다른 점은 하나입니다 — **쓰면 쓸수록 나를 배우고, 배운 만큼 믿고 맡길 수 있게 된다는 것.** 그 학습의 결과물(기억, 스킬, 커맨드, 에이전트)은 어떤 AI 벤더에도 속하지 않는 내 자산으로 남습니다.

## 나비 — 알에서 나비까지

naby 안에는 **나비**라는 에이전트가 있습니다. 나비는 대화 속에서 내가 어떻게 판단하는지를 배웁니다. 중요한 결정을 앞두면 자기 추천을 걸고 먼저 묻고, 내가 고른 답과 자기 추천이 얼마나 일치했는지가 그대로 성적이 됩니다.

이 성적은 알 → 애벌레 → 번데기 → 나비로 표시됩니다. 대화 횟수나 저장한 기억 개수로는 절대 오르지 않습니다. **먼저 묻고, 그 추천이 실제로 맞았는지만 셉니다.** 통계적으로 운이라고 보기 어려운 수준까지 맞혀야 나비가 되고, 판단이 어긋나기 시작하면 내려갑니다. 내려갈 때는 왜 내려갔는지를 이유와 함께 말합니다.

나비가 된 에이전트에게는 `@naby`로 일을 맡길 수 있습니다. "이 작업 끝까지 처리해. 중요한 판단만 나한테 물어봐" — 나비는 스스로 여러 단계를 밟고, 되돌릴 수 없는 결정 앞에서만 멈춰 묻고, 끝나면 무엇을 했고 무엇을 확인했는지 보고합니다.

## 대화가 곧 학습입니다

나비는 두 갈래로 배웁니다.

하나는 대화 중입니다. 배울 만한 사실을 발견하면 기억으로 제안하고, 내가 승인한 것만 다음 대화에 쓰입니다. 다른 하나는 대화가 끝난 뒤입니다. 나비는 지나간 세션을 되돌아보며 "묻지 않고 처리한 일을 사용자가 나중에 고쳤는가"를 스스로 찾아 성적에 반영하고, 여러 세션에서 반복 확인된 사실은 더 믿을 만한 기억으로 굳힙니다.

기억은 쌓아두기만 하지 않습니다. 오래 쓰이지 않은 기억은 우선순위가 낮아지고, 낡은 기억은 정리할 때가 되었다고 표시됩니다. 자동으로 지워지는 것은 없습니다 — 지우는 결정은 언제나 사람이 합니다.

## 기억의 주인은 나입니다

나비가 나에 대해 무엇을 기억하는지 전부 열어볼 수 있습니다. 검색하고, 직접 고치고, 지웁니다. 학습 자체를 끌 수도 있고, 특정 대화만 "학습 제외"로 표시할 수도 있습니다. 이미 배운 것은 계속 쓰되 새로 배우지만 않는 것과, 처음부터 기록을 남기지 않는 것을 구분해서 고를 수 있습니다.

학습된 나비는 파일로 내보낼 수 있습니다. 기억과 성장 기록이 함께 담기고, 다른 기기에서 불러올 수 있습니다. 다만 신뢰 등급까지 파일에 담겨 옮겨지지는 않습니다 — 새 기기에서 기록을 근거로 다시 계산됩니다.

## 하네스는 벤더 밖 내 자산입니다

스킬, 커맨드, 서브에이전트 같은 작업 도구를 naby에서는 하네스라고 부릅니다. 하네스는 `~/.naby` 폴더에 저장됩니다. Claude Code 같은 기존 도구의 자산을 가져올 수 있지만, 가져오는 순간 naby로 복사되어 내 것이 됩니다. 이후 벤더 디렉터리와는 아무 연결도 없습니다. 어떤 AI가 응답하든 — Claude 구독이든, ChatGPT든, API 키든 — 같은 하네스, 같은 기억, 같은 나비가 일합니다.

외부에서 가져온 도구는 꺼진 상태로 들어옵니다. 직접 켜기 전에는 대화에 쓰이지 않고, 채팅에서 내가 직접 설치하라고 시킨 것만 바로 켜집니다.

## 어디서든 나비와

컴퓨터 앞에 없어도 됩니다. 텔레그램 봇으로 세션 목록을 보고, 하나를 연결하고, 평소처럼 대화하면 그 세션에서 일이 돌아갑니다. 나비가 일하다 중요한 판단에 막히면 전화기로 물어오고, 버튼 하나로 승인합니다. 끝나면 결과가 도착합니다.

## 앞으로

naby가 향하는 곳은 분명합니다. **믿을 수 있게 된 만큼 더 많은 일을 맡길 수 있는 에이전트입니다.** 지금은 나비가 묻고 내가 답하며 신뢰를 쌓는 단계입니다. 나비가 충분히 나를 알게 되면 — 예약된 시간에 스스로 일을 시작하고, 내 편집 흔적에서 선호를 읽고, 처리 결과가 내 기준을 통과했는지 스스로 검증하는 — 점점 더 많은 일이 "시키는 것"에서 "맡겨두는 것"으로 넘어갑니다.

그 여정의 끝에서도 변하지 않는 것이 있습니다. 기억은 검토할 수 있고, 신뢰는 검증으로만 오르고, 자산은 벤더 밖 내 손에 있습니다.
