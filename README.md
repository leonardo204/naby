# 🦋 naby

**사용자를 학습한 만큼 위임 범위가 넓어지는 로컬 퍼스트 개인 에이전트 데스크톱.**

학습 결과(기억·스킬·커맨드·에이전트)는 사용자 컴퓨터에 남는 사용자 자산이며, 특정 AI 벤더에 종속되지 않습니다.

## 1. 개요

naby는 내장 에이전트 **나비**가 대화에서 사용자의 판단 기준을 학습하고, 학습의 신뢰도를 측정해 그만큼만 행동 권한을 넓히는 데스크톱 앱입니다. 신뢰도는 대화 횟수가 아니라 적중 기록으로만 계산됩니다 — 나비가 중요한 결정 앞에서 자기 추천을 기록하고 먼저 물으며, 사용자의 선택과 추천의 일치 여부가 그대로 성적이 됩니다.

## 2. 신뢰 단계와 권한

| 단계 | 행동 범위 | 자율 실행 |
|---|---|---|
| 🥚 알 | 읽기·조사·초안 작성 | 1스텝 |
| 🐛 애벌레 | 알과 동일 (학습량만 다름) | 1스텝 |
| 🛡 번데기 | 되돌릴 수 있는 변경(파일 쓰기·편집)까지 | 3스텝 |
| 🦋 나비 | 비가역 작업 포함 전체. 다단계 위임 가능 | 사용자 설정값 |

- 통계적으로 우연이라 보기 어려운 적중률에 도달해야 승급하고, 판단이 어긋나면 강등됩니다. 강등 시 사유를 함께 표시합니다.
- 범위 밖 요청에는 불가 사유, 대체 가능한 작업, 다음 단계까지 남은 수치를 답합니다. 수치는 실제 기록에서 계산됩니다.
- **빠른 성장 세션**: 나비가 질문으로 학습하고 연습 문제로 추천을 검증받는 전용 대화입니다. 연습 성적은 실전의 절반 가중치이며, 단계 측정의 시작은 실전 체크인으로만 가능합니다.

## 3. 학습

| 경로 | 동작 |
|---|---|
| 대화 중 제안 | 배울 만한 사실을 기억으로 제안하고, 사용자가 승인한 것만 이후 대화에 주입합니다 |
| 세션 회고 | 종료된 세션을 되짚어, 묻지 않고 처리한 일을 사용자가 나중에 수정했는지 찾아 성적에 반영합니다 |
| 교차 세션 확증 | 여러 세션에서 반복 확인된 사실은 신뢰도를 올립니다 |
| 기억 대체 | 새 사실이 옛 기억과 충돌하면 확정 시점에 대체합니다. 대체 이력이 남고 되돌릴 수 있습니다 |
| 스타일 학습 | 어미·문서 형식·결론 우선 같은 작업 유형별 선호를 학습합니다. 전체 어조 변경은 사용자 승인을 거칩니다 |

- 기억 전체를 열람·검색·수정·삭제할 수 있습니다. 자동 삭제는 없으며 삭제는 사용자만 실행합니다.
- 학습 전체를 끄거나, 특정 대화만 학습 제외로 표시할 수 있습니다.

## 4. 응답 재가공

모델이 사용자가 쓰지 않는 언어·어투로 답하면 나비가 출력 전에 응답을 재작성합니다. 의미는 바꾸지 않고 언어·어투만 고칩니다.

- 코드·명령·경로·숫자·식별자는 보존합니다. 검증에 실패한 재작성은 폐기하고 원문을 출력합니다.
- 같은 편차가 반복 관측되면 사전 지시를 주입해 재작성 호출 횟수를 줄입니다.

## 5. 백그라운드 작업 완료 보고

naby가 자식 프로세스를 소유해 종료 이벤트를 수신하고, 종료 시점에 해당 세션에 보고 턴을 엽니다.

| 전달 경로 | 조건 |
|---|---|
| 세션 메시지 + 읽지 않음 배지 | 기본 |
| OS 알림 | 앱이 포커스 밖이거나 다른 세션을 보는 중일 때 |
| 텔레그램 | 에스컬레이션 설정 시 |

- 이 메커니즘으로 시작하지 않은 작업에는 완료 통보를 약속하지 않습니다. 실행 수단이 없는 약속을 하지 않는 것이 원칙입니다.

## 6. 지원 엔진

엔진이 바뀌어도 기억·하네스·나비는 동일하게 동작합니다.

| 엔진 | 방식 | 비고 |
|---|---|---|
| Claude (구독) | 로컬 Claude Code 로그인 | 멀티 계정 등록·수동 전환, 플랜 사용 한도 표시 |
| Anthropic / OpenAI / Google Gemini / Azure OpenAI / Amazon Bedrock | API 키 | Gemini는 모델 목록 조회·세션별 선택 지원 |
| ChatGPT (구독) | OAuth | 비공식 백엔드(ToS 회색지대), 개인 개발용. 기본 활성, `NABY_ENABLE_CHATGPT_OAUTH=0`으로 끔 |

## 7. 원격 사용

텔레그램 봇으로 세션을 연결하면 채팅 메시지가 그대로 해당 세션의 턴이 됩니다. 나비가 판단 승인이 필요하면 텔레그램으로 질문을 보내고, 응답 버튼으로 승인하면 작업을 이어갑니다. 완료 시 결과를 회신합니다.

## 8. 하네스 소유권

스킬·커맨드·서브에이전트를 하네스라 부르며 `~/.naby`에 저장합니다.

- Claude Code 등 외부 도구의 자산을 가져오면 복사되어 naby 소유가 됩니다. 이후 벤더 디렉터리와 연결이 없습니다.
- 채팅에서 사용자가 직접 설치를 지시한 스킬은 활성 상태로, 외부에서 가져온 항목은 비활성 상태로 도착합니다. 비활성 항목은 사용자가 켜기 전까지 대화에 쓰이지 않습니다.

## 9. 기타 기능

| 기능 | 내용 |
|---|---|
| 세션 이어가기 | 컨텍스트가 차면 요약과 세션 환경(프로젝트 연결·기억·플랜 모드·텔레그램 링크)을 새 탭으로 승계합니다 |
| 예약 작업 | 지정 시각·주기·cron으로 나비가 턴을 시작합니다 |
| 실패 안내 | 턴 실패 시 프로바이더 원문 에러를 다음 전송 전까지 화면에 유지합니다 |
| 입력 이력 | 빈 입력창에서 `↑`로 이번 세션에 보낸 메시지를 불러와 수정 후 재전송합니다 |
| 에이전트 내보내기 | 학습된 나비를 파일로 내보내 다른 기기에서 불러옵니다. 신뢰 등급은 파일로 이전되지 않고 기록에서 재계산됩니다 |

## 10. 원칙

| # | 원칙 |
|---|---|
| 1 | 기억의 소유자는 사용자입니다. 전체 열람·수정·삭제가 가능하며 데이터는 사용자 컴퓨터에 남습니다 |
| 2 | 신뢰 등급은 적중 기록에서만 계산됩니다. 자기 채점·짐작으로 오르지 않습니다 |
| 3 | 실행 수단이 없는 일은 약속하지 않습니다. 불가 사유와 대안을 답합니다 |
