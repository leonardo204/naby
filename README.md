# naby — 나를 학습해 나를 대신하는 에이전트

naby는 데스크톱에서 쓰는 개인 에이전트 앱입니다. AI에게 일을 시키는 도구는 많습니다. naby가 다른 점은 하나입니다 — **쓰면 쓸수록 나를 배우고, 배운 만큼 믿고 맡길 수 있게 된다는 것.** 그 학습의 결과물(기억, 스킬, 커맨드, 에이전트)은 어떤 AI 벤더에도 속하지 않는 내 자산으로 남습니다.

## 나비 — 알에서 나비까지

naby 안에는 **나비**라는 에이전트가 있습니다. 나비는 대화 속에서 내가 어떻게 판단하는지를 배우고, 그 배움이 얼마나 믿을 만한지는 알 → 애벌레 → 번데기 → 나비 네 단계로 표시됩니다.

### 신뢰는 맞힌 기록으로만 쌓입니다

단계는 대화 횟수나 저장한 기억 개수로는 절대 오르지 않습니다. 나비는 중요한 결정을 앞두면 자기 추천을 걸고 먼저 묻고, 내가 고른 답과 그 추천이 얼마나 일치했는지가 그대로 성적이 됩니다. 통계적으로 운이라고 보기 어려운 수준까지 맞혀야 나비가 되고, 판단이 어긋나기 시작하면 내려갑니다. 내려갈 때는 왜 내려갔는지를 이유와 함께 말합니다.

### 단계가 곧 권한입니다

나비는 어느 단계에서든 `@naby`로 부를 수 있습니다. 다만 단계가 행동 범위를 정합니다. 알은 읽고, 조사하고, 초안을 만드는 것까지. 번데기가 되면 되돌릴 수 있는 일은 스스로 처리합니다. 여러 단계를 밟는 일을 통째로 맡기는 것 — "이 작업 끝까지 처리해. 중요한 판단만 나한테 물어봐" — 은 나비가 된 뒤의 이야기입니다.

범위 밖의 요청을 받으면 나비는 정직하게 말합니다. 무엇이 안 되는지, 대신 무엇을 해줄 수 있는지, 다음 단계까지 무엇이 남았는지. 이 숫자는 나비가 짐작하는 것이 아니라 실제 기록에서 계산됩니다.

### 기다리기 답답하다면 — 빠른 성장 세션

성장을 앞당기는 전용 대화가 있습니다. 나비가 나에게 가벼운 질문을 던져 배우고, 배운 것으로 연습 문제를 만들어 자기 추천을 걸고 내 답을 받아 봅니다. 연습 성적도 게이지에 들어가되 실전의 절반 무게입니다. 단계 측정 자체는 실제 작업 속 체크인으로만 시작됩니다 — 자기가 낸 시험으로 승급하는 길은 처음부터 막아 두었습니다.

## 대화가 곧 학습입니다

### 배우는 길은 하나가 아닙니다

대화 중에 배울 만한 사실을 발견하면 기억으로 제안하고, 내가 승인한 것만 다음 대화에 쓰입니다. 대화가 끝난 뒤에는 지나간 세션을 되돌아봅니다 — 묻지 않고 처리한 일을 사용자가 나중에 고쳤는지를 스스로 찾아 성적에 반영하고, 여러 세션에서 반복 확인된 사실은 더 믿을 만한 기억으로 굳힙니다.

### 기억은 쌓이기만 하지 않습니다

새로 배운 사실이 옛 기억과 부딪히면, 새 기억이 확정되는 순간 옛 기억을 대체합니다. 대체된 기억도 지워지지 않고 이력으로 남아 언제든 되돌릴 수 있습니다. 자주 쓰이는 기억은 천천히 늙고, 오래 쓰이지 않은 기억은 정리할 때가 되었다고 표시됩니다. 자동으로 지워지는 것은 없습니다 — 지우는 결정은 언제나 사람이 합니다.

### 말투도 배웁니다

나비는 사실만 배우는 것이 아닙니다. 어떤 어미를 쓰는지, 결론을 먼저 듣고 싶어하는지, 문서를 어떤 형식으로 원하는지 — 내가 고치고 다시 요청한 흔적에서 작업 유형별 선호를 읽어 냅니다. 다만 전체 어조를 바꾸는 학습만큼은 반드시 내 승인을 거칩니다. 나도 모르는 사이에 에이전트의 말투가 바뀌는 일은 없습니다.

### 배운 말투로 답을 다듬습니다

배운 것은 쓰여야 의미가 있습니다. 모델이 갑자기 낯선 언어로 답하거나 내가 쓰지 않는 어투로 답하면, 나비가 사용자에게 나가기 전에 표면을 고쳐 냅니다. 뜻은 건드리지 않습니다 — 코드와 명령, 경로와 숫자는 글자 그대로 남고, 검증을 통과하지 못한 손질은 조용히 버려지고 원문이 나갑니다. 나비가 자랄수록 이 손질은 촘촘해집니다. 그리고 같은 어긋남이 반복되면 나비는 애초에 어긋나지 않도록 미리 손을 씁니다 — **고쳐 쓰는 횟수를 스스로 줄여 갑니다.**

## 기억의 주인은 나입니다

나비가 나에 대해 무엇을 기억하는지 전부 열어볼 수 있습니다. 검색하고, 직접 고치고, 지웁니다. 내 결정이 필요한 것 — 새 기억 제안, 말투 학습, 기억 대체 알림 — 은 한자리에 모여 기다립니다. 학습 자체를 끌 수도 있고, 특정 대화만 "학습 제외"로 표시할 수도 있습니다. 이미 배운 것은 계속 쓰되 새로 배우지만 않는 것과, 처음부터 기록을 남기지 않는 것을 구분해서 고를 수 있습니다.

학습된 나비는 파일로 내보낼 수 있습니다. 기억과 성장 기록이 함께 담기고, 다른 기기에서 불러올 수 있습니다. 다만 신뢰 등급까지 파일에 담겨 옮겨지지는 않습니다 — 새 기기에서 기록을 근거로 다시 계산됩니다.

## 하네스는 벤더 밖 내 자산입니다

스킬, 커맨드, 서브에이전트 같은 작업 도구를 naby에서는 하네스라고 부릅니다. 하네스는 `~/.naby` 폴더에 저장됩니다. Claude Code 같은 기존 도구의 자산을 가져올 수 있지만, 가져오는 순간 naby로 복사되어 내 것이 됩니다. 이후 벤더 디렉터리와는 아무 연결도 없습니다. 어떤 AI가 응답하든 — Claude 구독이든, ChatGPT든, API 키든 — 같은 하네스, 같은 기억, 같은 나비가 일합니다.

채팅에서 내가 직접 설치하라고 시킨 스킬은 켜진 채로 도착해 바로 `/`에서 쓸 수 있습니다. 외부에서 가져온 도구는 꺼진 상태로 들어오고, 직접 켜기 전에는 대화에 쓰이지 않습니다.

## 어디서든 나비와

컴퓨터 앞에 없어도 됩니다. 텔레그램 봇으로 세션 목록을 보고, 하나를 연결하고, 평소처럼 대화하면 그 세션에서 일이 돌아갑니다. 나비가 일하다 중요한 판단에 막히면 전화기로 물어오고, 버튼 하나로 승인합니다. 끝나면 결과가 도착합니다.

## 앞으로

naby가 향하는 곳은 분명합니다. **믿을 수 있게 된 만큼 더 많은 일을 맡길 수 있는 에이전트입니다.** 지금은 나비가 묻고 내가 답하며 신뢰를 쌓는 단계입니다. 나비가 충분히 나를 알게 되면 — 예약된 시간에 스스로 일을 시작하고, 내 편집 흔적에서 선호를 읽고, 처리 결과가 내 기준을 통과했는지 스스로 검증하는 — 점점 더 많은 일이 "시키는 것"에서 "맡겨두는 것"으로 넘어갑니다.

어디까지 가더라도 원칙은 바뀌지 않습니다. 나비가 무엇을 기억하는지는 언제든 열어 확인할 수 있고, 신뢰는 실제로 맞힌 기록으로만 쌓이며, 배운 것은 전부 내 컴퓨터에 내 것으로 남습니다.
